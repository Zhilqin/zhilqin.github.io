# Zhilun Qin's Academic Homepage

This repository contains the source files for my personal academic website.

I am an incoming Ph.D. student at Tongji University, starting in Fall 2027. My research interests include robotic localization and mapping, 3D computer vision, and underwater robotics.

**Website:** [zhilqin.github.io](https://zhilqin.github.io/)

## Content

The website includes my biography, research interests, and education. Research projects and publications will be added as my work progresses.

- `index.md`: homepage content
- `_config.yml`: profile information and website settings
- `assets/`: images, styles, and other website resources
